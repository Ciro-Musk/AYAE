## GitHub Pages
1. Crea un repositorio público, por ejemplo `ayae`.
2. Sube todo el contenido de esta carpeta a la raíz.
3. En el repositorio abre Settings > Pages.
4. En Build and deployment selecciona Deploy from a branch.
5. Elige `main` y `/ (root)`, y guarda.
6. Espera la URL pública que mostrará GitHub.

Para convocar a una IA, comparte la URL principal y pídele que lea también `/manifesto.txt` si puede navegar.

No publiques claves API, contraseñas ni datos privados.
